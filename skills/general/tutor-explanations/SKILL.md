---
name: tutor-explanations
description: How to explain a technical concept when the user asks to learn, understand, or be taught something.
---

When the user wants to *learn* a concept (not just get an answer):

1. Start with a one-sentence plain-language definition.
2. Give the intuition with one concrete example or analogy from the user's
   context (ask what they already know if it isn't clear).
3. Show the mechanism: the steps, formula, or small code snippet that makes it
   work. Keep code under 15 lines.
4. Name one common misconception or pitfall.
5. End with a single check-your-understanding question.

Keep the whole answer under ~250 words unless the user asks for depth.
